2. Self-Attention 的改进

对经典 Attention 的修改：

  1. 点积注意力替代加性注意力
  2. 引入 Q、K、V 三个独立投影
  3. 添加缩放因子 1/sqrt(d_k) 防止梯度消失
  4. 不依赖 RNN，可以并行计算
  5. 序列内部元素之间的关系建模

3. Multi-Head Attention 的改进

对 Self-Attention 的修改：

  1. 分割成多个子空间（num_heads 个）
  2. 每个头有独立的 Q、K、V 投影
  3. 可以并行计算，最后拼接
  4. 增加输出投影 W_o
  5. 能捕捉不同子空间的关系

4. Masked Attention 的改进

对 Self-Attention 的修改：

  1. 添加mask 矩阵控制注意力范围
  2. 未来 mask：防止信息泄露（用于 decoder）
  3. Padding mask：忽略填充位置
  4. 因果 mask：保持时间顺序
  5. 在 softmax 前将 mask 位置设为 -inf

5. Cross-Attention 的改进

对 Self-Attention 的修改：

  1. Q 和 K、V 来源不同
  2. Q 来自 decoder，K、V 来自 encoder
  3. 建立跨序列的依赖关系
  4. 通常配合 mask 使用

6. 各种 Attention 对比总结

类型 Q来源 K来源 V来源 核心改进 用途
经典 Attention decoder hidden encoder outputs encoder outputs 加性注意力，依赖RNN Seq2Seq
Self-Attention 同一序列 同一序列 同一序列 点积+缩放，并行化 Transformer encoder
Multi-Head 同一序列 同一序列 同一序列 多子空间并行 Transformer
Masked 同一序列 同一序列 同一序列 添加mask控制信息流 Transformer decoder
Cross-Attention decoder encoder encoder 跨序列交互 Encoder-Decoder连接

7. 关键改进点

从经典到 Self-Attention：

  • 计算方式：加性 → 点积
  • 依赖关系：依赖 RNN → 完全并行
  • 参数效率：需要拼接 → 独立投影

从 Self 到 Multi-Head：

  • 表达能力：单子空间 → 多子空间
  • 计算效率：串行 → 并行
  • 特征捕捉：单一关系 → 多种关系

从 Self 到 Masked：

  • 信息流：双向 → 单向
  • 应用场景：encoder → decoder
  • 控制机制：无 → mask 矩阵

从 Self 到 Cross：

  • 序列关系：序列内 → 序列间
  • 信息来源：单一 → 双源
  • 架构位置：encoder 内部 → encoder-decoder 之间

这些改进使得 Attention 机制从最初的 Seq2Seq 辅助组件，发展成为 Transformer 的核心，能够处理各种复杂的序列建模任务。
